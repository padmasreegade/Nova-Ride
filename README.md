It can be difficult to find a university shuttle at the appropriate moment, or go meet the public safety department, particularly when timetables change and there is no real-time information accessible. Nova Ride is a smart shuttle tracking service that uses GPS on devices in the shuttle to give students real-time updates.  It makes the out-of-campus transportation easy and more comfortable by showing students exactly where the shuttles are, when they'll arrive, and if there are any route changes.  By connecting driver schedules with live location data, Nova Ride makes getting around campus more reliable for everyone.  Nova Ride API can be integrated either in the university website or nova safe mobile application or both to enable students, staff and faculty to plan their commute with confidence rather than relying on outdated schedules or asking other drivers around.
